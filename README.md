# HOOP RATING 籃球能力值評級

回答幾個問題，捏一個像素球員，生成像遊戲一樣的球員卡：六角雷達圖、AI 評語、NBA / WNBA 風格對照，還能存成圖片分享到社群。

純前端網頁（HTML / CSS / JavaScript），沒有後端、沒有帳號。所有資料只存在使用者自己的瀏覽器（localStorage），大頭照也只在瀏覽器裡處理，不會上傳。

## 本機執行

在這個資料夾裡開一個簡單的靜態伺服器就可以，例如：

```
python -m http.server 5173
```

然後打開 http://localhost:5173 。

## 檔案說明

| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css` | 介面與像素風樣式 |
| `app.js` | 問答流程、角色建立、結果頁 |
| `calc.js` | 評分、AI 評語、風格對照、標籤 |
| `data.js` | 各層級基準數據與球星模板 |
| `card.js`、`sprite.js`、`court.js` | 球員卡、像素球員、投籃熱區 |
| `audio.js` | 音效與背景音樂（用瀏覽器即時合成，沒有任何音檔） |
